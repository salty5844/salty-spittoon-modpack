# Salty Spittoon Minecraft Modpack

The Salty Spittoon Minecraft Modpack installer enhances your Minecraft experience by installing a curated set of performance, visual, and utility mods directly into your `.minecraft` directory.

It automatically installs the Fabric Loader, adds supported resource packs and shaders, and creates a dedicated launcher profile for seamless access to the modpack.

### System Requirements

| Minimum | Recommended |
| --- | --- |
| **OS:** Windows 10 (64-bit) | **OS:** Windows 10/11 (64-bit) |
| **Processor:** Intel Core i5-8400 / AMD Ryzen 5 2600 | **Processor:** Intel Core i7-10700 / AMD Ryzen 7 3700X or better |
| **Memory:** 8 GB RAM | **Memory:** 16 GB RAM |
| **Graphics:** NVIDIA GTX 1060 6GB / AMD RX 580 | **Graphics:** NVIDIA RTX 3060 / AMD RX 6700 XT or better |
| **Storage:** 8 GB available space | **Storage:** 20+ GB available space (SSD) |
| **Additional Notes:** Requires Java 25 and a Minecraft Java Edition account signed into the Minecraft Launcher | **Additional Notes:** Requires Java 25 and a Minecraft Java Edition account signed into the Minecraft Launcher |
